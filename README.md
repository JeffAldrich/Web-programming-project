JAC — Timeless & Limitless

A men's formal wear e-commerce website built with PHP and MySQL. JAC offers timeless suits crafted with minimalist design andexceptional quality — classic tailoring, modern confidence, made to last.

Features:
Customer

-Register and log in to a personal account
-Browse the collection by category (Suits, Shirts, Vests, Trousers, Accessories)
-View product details with size and color variants
-Add products to cart and place orders
-Order tracking (Pending, Processing, Shipped, Cancelled)
-Wishlist for saving favorite items
-Newsletter subscription
-Welcome back popup for returning users

Admin:

-Admin dashboard
-Customer management
-Inventory / product management
-Order management

Tech Stack:

Frontend: HTML, CSS, JavaScript
Backend: PHP
Database: MySQL (MariaDB)
Server: Apache (XAMPP)

Getting Started:
Prerequisites

-XAMPP (Apache + MySQL)

Installation:

1.Clone or download this project into C:\xampp\htdocs\
2.Start Apache and MySQL in the XAMPP Control Panel
3.Open phpMyAdmin
4.Import the database:
-Click Import
-Choose database.sql
-Click Go

5.Open the site in your browser:
http://localhost/Web-programming-project/

Admin account:

http://localhost/JAC/admin/login.php
